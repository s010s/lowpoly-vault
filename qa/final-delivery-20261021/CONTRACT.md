The protected scripts/final_delivery_fixed.py literal binds the two exact independently reviewed summary byte strings, source/review commits, all seven original artifact roles, original QA report hashes, primary and supplementary archive manifests. Its independent consumer review SHA is 0f748f26dab8f9b8462fa560dac9800a2b171c7f79d72efe523364d6ef875ce4. The map and consumer are executable policy under existing protectedModelPath, not caller-created evidence. Changes require independent protected-source review and a new full-policy CI baseline. The production collector uses inspect_candidate_inputs: all seven actual retained roles are read and hashed. Final GLB metrics are recomputed using the unchanged pinned qa_glb.py at the original brief's 14000/6/30 limits. Neither producer metrics nor a self-reported PASS can authorize a candidate. The fixed summary authenticates independent scientific/visual provenance; numeric schema checks do not establish scientific truth.

Concept images, historical acceptance PNGs, expanded reports, debug arrays and failed histories are restored from privately verified original archives using public hash/member restoration indices. They are not reread by every release CI. This is an explicit new storage contract, not a claim of literal old-collector execution equivalence. No Drive locator, credential, private URL or new signing system is needed by CI.

Runtime/download inputs are final GLB and editable final Blend. Brief/config/generator/dependencies/references are provenance audit inputs, not a promise of one-click reconstruction. In particular the E/N repair generator requires archived original r002 Blend restored separately. That historical dependency is not placed in this package or automatically executed by current CI. Current final Blend can instead be reopened and its complete authored export collection re-exported directly; no repair generator is involved. Existing asset_common.py/qa_glb.py/check_source_export.py/check_reproducibility.py implement this retained verifier closure.

- npm run test:final-delivery:blend: Blender read-only reopen, whole authored collection re-export and original-semantic identity. Requires installed Blender compatible with the frozen original exporter. Never saves the original Blend.
- npm run final-delivery:prepare-capture: exact final-subject capture input plan only; no capture or presentation approval.
