# Leptomitus detail overlay review

This page-only correction opts the original and the matching material candidate into a default-pose layout with documented, versioned projection bounds. It does not change the stage, renderer, camera, pose, or either poster. Desktop titles stay in their original position unless their default text box intersects the model. The unobstructed left column is preferred; a right column is used only when the full heading does not otherwise fit. On mobile, only a button intersecting the model is moved into an available side gap; the same button, label, and focus order remain. A version outside the reviewed exact GLB hash and detail path gets the unmodified layout.

Run `node site/gallery/tests/detail-heading-policy-test.mjs` against each packaged version to verify the original or candidate GLB and canonical detail PNG bytes and their resource pin. Recheck projection bounds if the default camera framing, canonical screen shift, or versioned poster changes. The browser does not claim to verify the PNG digest from its catalog.

Scoped Chromium verified the original and the exact material candidate at 1440×1000, 1024×768, 800×768 (Chinese and English), 800×1000, 1024×540, and mobile simulations 360/390/430×844. Also verified 1440×900 with the real Chinese title forced to 88px, a text-size pressure test, not system browser zoom. The canonical poster was visible after the wheel bridge completed and before the gated GLB response; stage, heading, and button rectangles stayed constant through readiness in these fixed-view cases. Both variants also passed failed canonical-poster request with 3D fallback, failed GLB/retry, resize while gated and switch to a negative-control model. Keyboard info/focus and mobile Enter exit/re-enter passed. There is no active-rotation avoidance, universal narrow-column guarantee, physical-device claim, or all-model test here. No release is implied.
