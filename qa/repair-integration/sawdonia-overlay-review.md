# Sawdonia default-pose mobile overlay review

The exact existing 3,140,212 byte model stays in place. Its GLB, Blend, preview, wheel and detail image were checked against the hosted bytes and Git; no asset/manifest change is part of this patch. In the original 390×740 layout the upper interact control obscured the capsule tips and the lower tools obscured part of the stem. 430×844 also lost part of the lower stem.

The exact GLB hash and versioned canonical detail path opt this model into the shared overlay policy, using its measured default-pose projection. The existing buttons and labels move only on a real geometry conflict, before the canonical-image handoff. The lower tools become a vertical rail if a safe side fits, with a placeholder retaining the original flow geometry. The upper control uses a side column when possible, or an unobstructed band below the heading and above the model for the longer English label. The view, model pose, poster framing and download card stay fixed. If no safe slot fits, the existing controls/layout remain; this is not a general guarantee against collisions on tiny/short screens or when rotating/zooming the model by hand.

Scoped production-route Chromium checks: 360×844, 390×844, 430×844, 390×740, 390×920 (Chinese); real English labels on 390×740; desktop Chinese remains unchanged. Sawdonia rendered with canonical poster visible and bridge removed before release of the delayed matching GLB. No default-pose overlap was observed in the tested fixed layouts. Stage, canonical poster framing, held→ready control boxes and download card geometry remained unchanged where measured; GLB and both actual poster responses matched their pins. Checked touch, keyboard/Tab, rotate/reset, resize round-trip, Leptomitus and Confuciusornis negative controls, four real GLB/Blend downloads, and eight lifecycle checks. Only simulated viewports and bounded frames, not physical-device or arbitrary-view guarantees.
