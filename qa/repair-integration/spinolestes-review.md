# Spinolestes: scoped material-only gallery repair

The exact published model renders head-left, and its right poster and 3D endpoints already align. The original default glTF metallic factor (1 when omitted) heavily darkens the otherwise lighter face and toes and obscures the separation of some dorsal spines. Fixed source texture and WebGL camera/lighting comparisons at 0° and 180° used unlit as a diagnostic reference and .65, .35 and 0 as controlled material variants. At .65 the pale face and paws read separately from the original dark warm-brown back; naturally shadowed underbody areas remain. No exposure, light, tint, texture, orientation, UV, geometry or camera changes.

- Five HTTP resources (GLB, Blend, preview, wheel, and detail) were byte-matched to production main `d1fd39fa` and the scoped review input `100d2f0c`. Original GLB `67586471ee15618febc1392531ad352e4f0effe31babd2ebb6922cd33c2b969d`; repaired GLB `e820953fe900385faaf3b9c857046522928594dccd7efd6d7e2ddde725a07a8c`. Only the metallicFactor in GLB JSON changed; the binary chunk is byte-identical. glTF Validator: 0 errors and 0 warnings.
- The original downloadable Blender source was the paired packed import, not the historical authoring project. Only its unlinked Principled BSDF Metallic default was changed. Reopened Blend vs fresh candidate GLB import matched mesh topology and vertices, dimensions/transforms, UVs, texture pixels, and packed image bytes.
- The wheel and detail are regenerated through project WebGL and bound to the exact new GLB. Compared true gallery desktop 1440×1000 and touch-emulated 390×844 canonical right posters (while holding GLB) with actual exact GLB displayed after release. No obvious position, scale, angle, or color jump in those sampled endpoints. Original desktop/mobile CDP recorded 46/45 frames, candidate 43/40; original and new mobile each reported an out-of-order timestamp (approx. -5.1/-15.9 ms). This is endpoint/sampled verification, not proof of all frames or devices.
- Both actual poster responses, both actual download buttons and production-generated ZIP/credits were validated against exact bytes. Eight targeted interaction cases (rapid reselect, late response, retry, rotate/reset on both viewports) were checked on original and candidate. Full branch CI and physical mobile hardware are not covered here.
