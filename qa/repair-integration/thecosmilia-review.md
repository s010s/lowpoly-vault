# Thecosmilia material-only review

The live GLB, Blend, preview and both gallery posters matched the originals in Git. The previous fully metallic default obscured vertical texture on the lower tube walls. Independent four-angle review supported metallic 0.65 rather than brightening all the way to zero; inter-tube shadow and warm-brown colour remain. No geometry, texture, transform, authored scale or default pose change. GLB comparison parsed both versions and verified that only the metallic factor differs; the binary chunk is unchanged. The candidate Blender source was derived from this exact GLB, not represented as the original authoring project. Blender reopen verified mesh/UV/matrix data and non-empty packed 1024² texture pixels and bytes. Both GLBs validate with zero errors and warnings.

Source-matched detail and wheel images have exact resource pins. In a scoped build of the real gallery, independent review of withheld-GLB versus settled 3D showed no noticeable subject position, scale, angle, shape or colour/material discontinuity at 1440 desktop and 390 touch/mobile emulation. The candidate had 36 and 46 finite CDP frames, respectively, with no out-of-order timestamps or page errors; that is not physical-device or continuous-frame coverage. Both poster HTTP hashes and all four actual GLB/Blend downloads passed. Rapid reselection, late response, retry, and rotate/reset passed on both viewports (8 cases). The original authored measurement remains unchanged; biological scale is not asserted. Unified branch CI and production release are pending.
