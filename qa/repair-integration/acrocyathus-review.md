# Acrocyathus scoped material review

Compared the five actual production files against the Git original at `eeace2d9`: GLB, Blend, preview, wheel and detail are byte-identical. The original underreads several radial septa in shadowed cups, especially at 90° and 180°, where neighbouring cups visually run together. The smallest clearly useful control was effective metallic 1 to 0.65. Full removal was unnecessary. The new GLB (2,437,860 bytes, 33,000 triangles) changes only that field: all other GLB JSON and the BIN chunk remain identical. Geometry, default pose, dimensions, UV and authored texture were not altered. The matching editable Blend was reimported from the exact GLB, packed and reopened; geometry, UV, matrix and nonempty image fingerprint match the import. This is not the original authoring session.

Generated wheel and detail from the exact repaired asset, using the current wheel and preview renderer and unchanged framing. Confirmed HTTP bytes for both rebuilt posters and four desktop/mobile UI downloads. Original and candidate each passed eight scoped lifecycle cases (two widths × rapid reselect, late response, retry, rotate/reset) and glTF validation reported zero errors or warnings. Independent review found clearly distinguishable rims and radial septa with natural depth shading, and no visible movement, scale, yaw or material discontinuity between the settled canonical detail poster and loaded 3D in the sampled endpoints. Desktop 1440 and simulated touch 390 captured original 50/54 and candidate 49/58 frames. Candidate CDP order had one timestamp inversion per viewport, no page errors. This is finite sampling and not a continuous-frame or physical-device certification.

No production deployment, release claim or scientific-authenticity certification. Unified repair-branch integration and branch CI remain pending from this local commit.
