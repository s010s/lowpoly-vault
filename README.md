# Lowpoly Vault

Original low-poly assets for building small worlds.

By **Leon Made This / [s010s](https://github.com/s010s)** · [简体中文](README.zh-CN.md) · [CC BY 4.0](LICENSE)

Lowpoly Vault is a growing library of original, stylized 3D assets made with Blender. It starts with prehistoric environments, with room for many more worlds: natural landscapes, imagined places, and whatever comes next.

## First collection: prehistoric environments

**In progress.** The first collection is being built around ten asset types:

- Layered rock cliff
- Natural stone arch
- Conifer tree
- Cycad-like plant
- Ground-cover fern cluster
- Horsetail colony
- Fallen tree with exposed roots
- Dinosaur egg nest
- Three-toed footprint mud slab
- Carboniferous *Lepidodendron* (scale tree)

These are stylized assets for teaching and creative scene-building, not rigorous species reconstructions or a reconstruction of one place and time. *Lepidodendron* belongs to the Carboniferous context; the egg nest and footprints are illustrative motifs, not evidence for a specific dinosaur species. Combining assets does not imply that their real-world counterparts coexisted.

## What the vault will include

The following deliverables are **planned or in progress**, not yet a complete release:

- **Blender sources (`.blend`)** for editing and learning
- **GLB models (`.glb`)** for real-time scenes and web previews
- **PNG previews (`.png`)** for browsing and reference
- **Reproducible scripts** for generating assets and exporting deliverables
- **Skills** documenting repeatable modeling and production workflows
- **A categorized Web 3D gallery**, with interactive model previews
- **GitHub Pages hosting** for the gallery, once deployment is verified

This README will gain usage instructions and a gallery link as those pieces become available.
