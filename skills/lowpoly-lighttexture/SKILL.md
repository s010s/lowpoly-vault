# Credible low-poly + lightweight textures

Use this for **new, not-yet-frozen** lowpoly-vault sequences. Read [the technical profile](references/lighttexture-profile.md), then instantiate [the dispatch template](templates/future-dispatch.md) with the real research evidence, budget, authority and asset ID. This is the project-local Skill entrypoint; dispatchers must pass its path and relevant references to workers explicitly. It is not an installed global Skill.

The user accepted the visible improvement in the 2026-10-29 texture experiment and requested this direction, not a mandatory multi-tier experiment per asset. Preserve credible reference-based silhouette, scale/proportion, anatomical or structural connections and material regions. Texture cannot repair the wrong shape, disconnected fins/limbs, floating parts or misleading anatomy. Low-poly is a deliberate allocation of geometry, not permission for primitive-looking or false forms.

Default to a small original base-color map where it improves material/region readability. Add subtle normal or roughness maps only when useful. Do not decorate every surface with generic noise or copy reference photos into textures without rights. Record uncertain reconstruction choices as artistic choices, not facts. Keep reference provenance and existing concept/research obligations.

**Authority boundary:** ordinary new dispatch is paused. The user's later request allows only four bounded trials (two new models and two existing-model surface refits) after repository integration and fresh independent review; root selects and launches those separately. This Skill does not itself start models, grant another attempt, modify frozen work, or authorize upload/merge/deployment of models. For the current four-item exception read [the temporary trial contract](../../docs/trials/lighttexture-four-20261029.md); it is not a permanent budget. Previously dispatched work keeps its old contract. Failed/HOLD candidates do not become “new” by changing profile.

Keep the technical profile `lowpoly-lighttexture-v1` separate from budget/dispatch profile `normal-new-original1plus1`: one original candidate plus one unchanged verification, original UNKNOWN/debit semantics and fresh independent QA remain unchanged. No per-model texture experiments, retry allowance, alternative candidate selection or extra builds are created by this default. Freeze maps, UV, source, config, exporter and report helper before original generation. The unchanged verification uses those exact frozen inputs; missing required evidence remains UNKNOWN/HOLD, not PASS.

Deliver editable source, original texture files/provenance, generator/config, exact standalone GLB and its hashes, actual-GLB screenshots and lightweight technical report. Fresh independent QA sees raw references, actual export and evidence before the maker's verdict; inspect shape and connections as well as seams, stretching, color bleed, repeated pattern scale and shading. Retain existing count/capacity, source/rebuild, factual and release gates. This profile adds no mandatory camera count, universal file cap or texture dimension gate.
