# 实验记录与经验回写

用于有具体假设的局部试验，不给每个普通修色新增一套审批。复用已有制作/QA 记录；以下模板可直接引用现有路径和哈希，不重复抄账。先记目标与基线，结束时补实测、失败和下一步；尚未完成的项保持 `null` / `pending`，不预填成功。

仅记录经验不要求新开制作或补图。只改法线/粗糙度等局部变量时，可复用仍适用的配色方案和检查；最终复核仍覆盖实际改动及其呈现影响，不借此跳过必要验收。

不要将服务等待、烘焙/渲染计算和主动编辑混作净工时；未连续计时就写未记录。效果、体积和速度分别比较，同一试验改善其中一项不代表其他项也通过。相机或灯光同时改变时，只对控制变量支持的效果作归因。独立 QA 和用户评价分开保存，缺任一所需结论就保留待定，不用“无报错”代替。

## 从一次试验提炼什么

- **实验中/实验性（experimental）**：方法尚待验证或只有局部证据。可以记下观测到的失败、诊断办法和待验假设；不得称为可靠材质方案或据此承诺批量速度。
- **本物种已验证（species-validated）**：精确候选在约定部位、用途和观看条件下完成所需独立 QA；用户评价按实际状态另记，有待用户确认的目标不宣称已被用户接受。适用结论只覆盖这个范围，鼻部通过不等于全身或整物种所有模型通过。
- **多物种可复用（multi-species-reusable）**：同一方法在不同物种、具有代表性差异的形体/表面和目标条件中重复验证，保留各自参数、成本、失败边界与证据。只对这些条件声明复用，不以机械凑样本数或一次成功免除下一只的视觉检查；为验证而新增制作仍需本次任务范围覆盖。

这些标签描述证据强度，不是额外发布权限或强制审批流程。未成功的试验也能回写“如何识别此失败”的窄经验，但不能把单例失败写成普遍禁令。

按结论分别定级：同次实验可只有技术管线在该资产上达到 `species-validated`，艺术配方仍是 `experimental`、参考保真需修、用户评价待定。确定性重放证明该输入/配置可重放，不证明写实达标或跨物种适用。

## 回写到最小合适位置

稳定的判断方法写入本参考或相关阶段说明；可重放且有实际收益的操作才提炼成脚本。脚本将输入、输出、物种区域/尺度、材料强度和分辨率等暴露为参数，保留验证过的配置与适用条件，避免硬编码某只的路径/尺寸/颜色或把它变成所有模型默认材质。用真实输入重放并检查真实导出和比较证据；语法检查不是效果验证。

区分依赖当前几何的区域提取、中心线/方向与 UV 映射，和可复用的生成、烘焙、导出检查管线。前者保留适配方法及失败条件；把坐标常数改成命令行参数不等于已具备跨物种通用性，也不为一次局部试验强建批量框架。

公共 Skill 只保留可解释的做法、必要例证和边界；项目的原始图像、运行记录、私有定位与恢复材料留在项目记录中。已存在记录能证明结论就引用，不建立平行账本。当前试验尚无测量或评价时，先交付模板和待验项，取得证据后再做最小修订；保留被否定的假设，不反向改写历史。

## 一次局部鼻褶试验留下的窄经验

以下来自 2026-10-30 单个嵌齿象候选的局部 UV/法线/粗糙度实验。用户先评价耗时长、收益不足，后接受当前五只模型的视觉进入集成；后者不撤销前述投入产出判断，也不等于写实参考保真已达标。该配方不是厚皮动物通用材质，浏览器/设备结果另验。

- **先看整只的投入产出**：局部细化前，先在目标观看距离比较整只模型的可见改善，再决定细节投入。本次约 47.5 分钟的实验/验收经过窗口（非净操作工时）只换来小范围改善，未满足用户的价值预期；这套手工设定的局部程序配方不作为批量默认。这不普遍否定法线，也不证明参考驱动纹理等其他路线已经验证。
- **技术收益与艺术质量分开**：保持原三角形、法线和本色，局部细节在多角度/两套光照下可见，技术管线可以限定为该资产已验证；规律环带、全身观看距离收益有限仍属艺术局限。法线和粗糙度同时变化，未单独证实粗糙度收益。不要用更强法线或“有纹理”自动宣布自然皮褶通过。
- **先验证预览读取的资源**：在 Blender 4.3.2 的此次导入状态中，对已嵌入且尚未解码、文件路径为空的图像再次 `im.pack()`，未抛异常却清空了 packed 数据；同 GLB 去掉该操作后恢复。检查嵌入字节、实际像素及源文件保存/重开后的哈希，不能只看 `has_data`（延迟解码时可暂为 false）。这是版本/状态限定的失败，不是普遍禁止打包。
- **不要混淆并行修复的因果**：该试验还修复了运行时生成切线警告、17 个退化 UV 和端点投影问题，但先前“切线修好所以大面片伪影消失”的归因被撤回；完整与短诊断脚本的打包路径不同。保留单变量对照，分别核验 UV/切线与图像读取，技术无警告不等于视觉通过。
- **预算按实际表示测量**：该单例 GLB 为 762,396 → 885,980 bytes（增加 123,584，约 16.2%），两张 512×1024 PNG 共 69,676 bytes；按 RGBA8 加完整 mip 链估算约 5.33 MiB，不是实测显存。脚本构建/重放耗时不包含研究、失败诊断、制作与 QA，不能拿秒级重放承诺整只制作时间。
- **脚本先保留项目适配身份**：本例依赖指定网格/材质、固定属性格式、无交错步长和原本无图片的输入；它重建图片/纹理表，不能直接搬到已有纹理的资产。区域提取与中心线也专属于该几何。不支持的输入应在写文件前明确拒绝；拒绝测试不等于已支持这些输入。后续泛化须保护既有资源并验证代表性新输入，不以“参数已外置”代替这些工作。
