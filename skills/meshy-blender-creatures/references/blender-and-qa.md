# Blender 精修与真实 GLB 验收

## 形体优先

保留原始底模，改副本并记录版本。探测实际 Blender 与 glTF 导出器版本，不照搬某次环境的选项。按项目约定校对尺度、前向轴、地面接触和导出对象，不为缩略图统一大小而改变资产实际尺度。

先看灰模：主体比例、重心、头颈与肩胯连接、肢体承重和分离、口腔/牙齿根部、尾部及物种识别特征。区分真实结构问题与光照、法线、视角造成的假象。对疑点换灯或换视角，再决定修改；避免把图中没看见的结构直接判为缺失。

按可见问题选表示：轮廓、体块、深褶和重叠关系靠几何；浅褶、皮纹或短毛方向可用法线提示；大色区用本色，反光差异用粗糙度。法线图不改变真实轮廓，灯光也不能补出缺失结构。先看目标距离的整只收益，不为近景纹理牺牲已认可的形体与风格。

修复明确的形体问题后再减面。按区域保留轮廓曲率、薄结构、关节和口眼，优先简化平缓、隐蔽或重复密集区域。每轮对比同镜头灰模；不要把“一键全局减面后的面数更少”当作美术进步。三角面、导出顶点和源顶点分开记录。

## 表面与文件体积

### 粗上色检查

正式贴图、细节噪声或复杂材质之前，先读该物种研究与彩色美术参考的实际像素，确认它们仍适合本次造型和用途。已有合格参考直接复用并记版本/哈希；不足时只补相应视角或信息，不把补图当作必须重做底模的理由。

用一张简短分区调色表把参考落实到模型：身体区域、主/辅色与明度冷暖、边界位置/宽度、花纹形态/方向/密度（或明确无花纹）、依据与不确定性。背腹、头脸、四肢末端及识别特征按该物种实际需要列出，不套用全物种同一灰褐表。数值色样注明 sRGB 或 linear；不要把参考里的高光和投影误当固有色。不确定的古生物体色/花纹标为艺术复原，不因“生物研究约束”伪称已知，也不擅自添加无依据的装饰。

做低成本粗上色（简单材质、顶点色或低分辨率贴图均可），与彩色参考按相同或尽量对应的姿态、相机和尺度做多角度对照；分区应在目标观看距离可读。若视角不能严格对应，说明偏差，只判断可比较部分；缺失的关键视角不作 PASS。

关卡记录绑定参考与粗上色修订/哈希、调色表、对照图及复核者结论：主要分区/边界、明暗冷暖关系、必要花纹与关键部位可读且符合参考，才记视觉 PASS，进入正式表面制作；不符则先修调色表或粗色。无法复核标待完成，不用自动测试、材质存在或制作者口头自评代替。

ImageGen 输出是美术目标，不是与模型 UV 自动对应的纹理。选择贴图、投影后人工校正、程序材质或顶点色是实现方法；均须忠实转译目标。投影要处理遮挡、视角差、接缝与背侧缺失；不用位图不算失败，有位图也不证明转译成功。若现有素色分区已满足参考，不硬加花纹或细噪声。

先明确每张图解决什么：颜色分区、粗糙度变化或小尺度凹凸。材质因子、顶点色、小型基础色图和 PBR 贴图均可选；没有收益时不用图也是有效结果。可以用 1K 基础色、512 法线/打包粗糙度等作为某些展示模型的比较起点，但必须看实际用途，不能成为所有物种的上限或最低配置。

保护 UV 接缝、边缘留白、纹素密度和方向；检查法线贴图色彩空间/切线方向、凹凸强度与粗糙度。细纹理不等于真实，泛用噪声、高对比 AO 和亮点可能制造塑料感、脏缝或闪烁。材质使用目标 glTF 能携带的结构；仅在 Blender 生效的复杂节点需烘焙或转换。

新增局部 UV/法线时，检查有效坐标、退化三角形、方向/手性和接缝拆点，再核对真实 UV 对应的切线与重导入效果。运行时生成切线的警告是待核线索，不直接证明画面失败；无警告也不等于皮褶自然。保留未改区域及原有图片/材质，不让局部脚本静默丢弃既有资源。

先核对嵌入图片字节与实际解码像素，必要时验证源文件保存/重开，再判断表面。不要把空预览误诊为模型缺陷，也不要仅凭图片对象存在或保存无异常判通过；已嵌入资源勿盲目重复打包，具体版本案例见 [实验记录与经验回写](experiment-feedback.md)。最终仍以干净场景重载真实导出 GLB 的多角度表现为准。

GLB 变大不一定来自图片：UV、硬边、切线与材质边界会拆分导出顶点。分别测几何缓冲、顶点属性、图片 bytes 和总大小，再决定删图、降图、简化几何或整理材质。压缩后文件更小不自动代表 GPU 内存更低或帧率更高。

### 颜色与光照分离验收

独立复核者检查最终导出 GLB 的实际像素，而非只看贴图文件或节点。按目标和风险选多角度，至少覆盖主要分区、必要花纹及两侧/背腹等可能不同的区域；不要只凭一张英雄视角批准全身。每个可比较角度并列：

1. **reference**：已确认的彩色美术目标；形体另用对应灰模多视图审查。
2. **baseColor unlit**：最终 GLB 的实际组合基础色（贴图、顶点色、材质因子按其有效组合），暂时不受灯光、阴影、AO、法线或高光影响，检查本色分区与花纹。记录色彩空间、显示变换和曝光；诊断覆盖只在副本/内存中进行，不改候选文件。
3. **final lit**：同一 GLB 在中性可读灯光下及目标展示光照下的最终材质；若目标灯光已中性可读可复用同组图。记录相机、灯光、曝光与色彩管理，确认本色没有被洗白或吞黑，粗糙度/法线也不制造伪色、塑料感或脏缝。

参考图本身有光照，不要求逐像素 RGB 相同；重点比较区域关系、边界、花纹覆盖与识别效果。unlit 本色已弱，须修颜色转译，单纯降灯不能创造缺失分区；unlit 合格而 lit 失真，先隔离灯光/曝光/显示变换。控制变量再归因，不能看到灰白就断定缺贴图、UV 失败或某一显示变换有错。

分别给出“颜色设计/转译”和“灯光/材质呈现”的 PASS、需修或未测，定位问题与证据。若目标用途要求的视角或上述诊断缺失，独立颜色验收仍待完成；格式/加载检查通过不能补齐视觉结论。

## 有针对性的独立 QA

给复核者：目标与接受的简化、适用来源、原版/候选的精确 GLB、变更摘要、技术记录。第一次判断不附制作者自评分。先形成自己的观察，再讨论差异；不要要求复核者猜隐藏的用户标准。

- **真实导出**：干净场景加载最终 GLB，看实际图片像素。灰模检查形体，带材质检查颜色、UV、接缝与法线；按风险选择侧面、正面、背面、顶面或局部，不强加一个通用固定镜头数。
- **公平比较**：尽量相同几何版本、相机、尺度、灯光、曝光与色彩管理。若同时改了几何与贴图，不能把全部提升归因于贴图。
- **技术检查**：用可用的标准 glTF 验证器查格式；另查缺图、错误材质、异常法线、对象遗漏和资源预算。结构解析通过不等于画面通过。
- **用途检查**：静态预览结论限于已看视图；要交付互动应用，检查实际加载、旋转/缩放、mipmap、光照与所需设备性能。要用于动画，另查拓扑、骨骼和变形；不能沿用静态结论。
- **取舍校准**：允许任务认可的简化眼睛、规则牙齿、少量平面感；只有损害识别、结构或目标用途时才列问题。不能因未达到摄影级真实就一概拒绝，也不能因为文件能打开就接受。

报告用“已通过的范围 / 尚存问题 / 未测项 / 下一步”即可。局部瑕疵说明位置和影响；只影响该用途的小修不必重启整个底模流程。对必要但未测的项目标待完成，不自动把全部成果判死刑；对真正失败说明修复或换路线的依据。

## 可持续复用

少量代表任务验证后，再把稳定的参数与适用边界写入项目配置。不要把首个样本的工时、体积、预算或用户偏好升级成所有资产的硬规则。修订模型后按变更复查相关证据；未变且仍适用的来源、工具验证和技术检查可复用。
