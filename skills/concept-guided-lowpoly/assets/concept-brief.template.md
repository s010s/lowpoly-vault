## ImageGen prompt to adapt

Generate an original low-poly DESIGN CONCEPT for [subject], before any model is built.
Use [matte/faceted/mixed style], [palette and material regions], [neutral background],
[lighting], [projection and orientation]. Keep the whole object in frame.
Dimensions/proportions: [width/depth/height]. Preserve [three defining landmarks].
Primary mass: [shape]. Secondary structure: [shape, hierarchy and negative space].
Quiet region: [area]. Avoid [specific unwanted forms]. No text, UI or decorative props.

If extra views are needed: show compatible front, side and top views of the SAME
object, at consistent scale and orientation, with the same landmark/branch/fin
counts, palette boundaries and thickness. Do not redesign it between panels.
These are design suggestions, not guaranteed orthographic measurements.
