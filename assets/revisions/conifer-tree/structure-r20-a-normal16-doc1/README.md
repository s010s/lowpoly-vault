# Airy conifer tree / 轻透针叶树

General stylized conifer concept, not a named fossil species or habitat reconstruction. Requires KHR_mesh_quantization; tested with Three.js 0.180.0. Scene frame-budget acceptance is limited to the measured Apple M5 Pro/ANGLE Metal, Chromium 141, DPR 1, 1200×900, no-shadow profile. SwiftShader does not meet the 16.7 ms target, including single-tree tests. Fine needles can show subpixel aliasing in motion. Other devices and loaders are unverified.

通用风格化针叶树概念，不是命名化石物种或栖息地复原。需要 KHR_mesh_quantization，已测试 Three.js 0.180.0。场景帧预算通过仅限实测 Apple M5 Pro/ANGLE Metal、Chromium 141、DPR 1、1200×900、无阴影配置；SwiftShader 包括单棵测试均未满足16.7毫秒目标。细针运动时可有亚像素边缘跳动。其他设备与加载器未验证。
