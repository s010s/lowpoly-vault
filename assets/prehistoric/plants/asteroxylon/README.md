# asteroxylon: static artistic environment prop

This is an original stylized-inspired prop for an imaginative children's prehistoric world, not a strict scientific reconstruction. Color, pose, fine details and conservative restored parts are artistic. No rig or animation is included.

## Recovery provenance

The GLB was regenerated in Blender 4.3.2 from preserved source on 2026-10-18. Its SHA256 is **028eca80ede2eb4fc95f87c17465aee8dd3284c43d3d5633cb8343db91abcc8e**, matching the previously recorded original GLB byte-for-byte. The editable .blend and rendered evidence are newly generated; their original-byte identity is not claimed.
