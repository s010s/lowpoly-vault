# Bothriolepis · static artistic interpretation

Original low-poly prop for an imaginative children's prehistoric world. Inspired by Bothriolepis canadensis; color, fine details and pose are artistic. This is not a strict scientific reconstruction.

- Editable source: `bothriolepis.blend`
- Standalone web asset: `bothriolepis.glb`
- Generator: `scripts/models/small_fauna/build_aquatic_pair.py` and its adjacent geometry helper
- Rebuild parameters/material palette: `build-config.json`
- Transparent source thumbnail: `preview-hero.png`
- Six exact-GLB diagnostic views and hashed manifest: `views-r001-final/`
- Contact sheet: `qa-contact-sheet.webp`; supported-size inspection: `qa-supported-scale.webp`
- Frozen art brief/reference ledger: `brief.json`, `references.json`, `freeze.json`; `execution-brief.json` adds exact deliverable hashes without changing the art brief

Measured export: 736 triangles, 8 primitives, 4 opaque palette materials, 46,000 bytes. Nominal body length 0.44 m. Asset coordinates are meters, glTF +Y up / +Z forward. The identity root is the declared suspended body-center mounting point; the asset is not ground-aligned.

Source/export count and bounds, clean GLB reimport, official Khronos format validation and a separately executed deterministic rebuild have completed. See `technical-summary.json` and the individual reports. Pinned Three.js 0.180.0 Node GLTFLoader parsing also passes with matching bounds/counts. Independent art/specification approval, actual graphics rendering and repeated-scene review remain pending. The source image is not evidence of WebGL rendering. No rig or animation is included.
