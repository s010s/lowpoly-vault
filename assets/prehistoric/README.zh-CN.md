# 史前环境

[English](README.md) · [许可与署名](../../ATTRIBUTION.md)

## 系列范围

**制作中。** 首批围绕以下十类资产展开：

- 层理岩崖
- 天然石拱
- 针叶乔木
- 苏铁形植株
- 地被蕨丛
- 木贼群落
- 连根倒木
- 恐龙卵窝
- 三趾足迹泥板
- 石炭纪鳞木（*Lepidodendron*）

这些是面向教学与创意场景搭建的风格化资产，不是严谨的物种复原，也不是同一地点、同一时代的生态复原。鳞木对应石炭纪背景；卵窝与足迹为示意性元素，不指认具体恐龙物种。将资产组合使用，并不代表其现实原型曾经共存。
