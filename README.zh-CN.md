# Lowpoly Vault

用原创 low-poly 资产，搭建自己的小世界。

作者：**Leon Made This / [s010s](https://github.com/s010s)** · [English](README.md) · [CC BY 4.0](LICENSE)

Lowpoly Vault 是一个持续生长的原创风格化 3D 资产库，使用 Blender 制作。从史前环境出发，未来也会探索自然景观、想象中的地点，以及更多不同的世界。

## 首批：史前环境

**制作中。** 首批围绕以下十类资产展开：

- 层理岩崖
- 天然石拱
- 针叶乔木
- 苏铁形植株
- 地被蕨丛
- 木贼群落
- 连根倒木
- 恐龙卵窝
- 三趾足迹泥板
- 石炭纪鳞木（*Lepidodendron*）

这些是面向教学与创意场景搭建的风格化资产，不是严谨的物种复原，也不是同一地点、同一时代的生态复原。鳞木对应石炭纪背景；卵窝与足迹为示意性元素，不指认具体恐龙物种。将资产组合使用，并不代表其现实原型曾经共存。

## 资产库将包含什么

以下内容目前处于**计划中或制作中**，尚未构成完整发布版本：

- **Blender 源文件（`.blend`）**：方便编辑与学习
- **GLB 模型（`.glb`）**：用于实时场景与网页预览
- **PNG 预览图（`.png`）**：方便浏览与参考
- **可重现脚本**：生成资产并导出交付文件
- **Skills**：记录可重复使用的建模与制作流程
- **分类 Web 3D 展厅**：提供交互式模型预览
- **GitHub Pages 托管**：部署验证通过后开放展厅

随着各部分完成，这份 README 会补充使用说明与经过验证的展厅链接。
