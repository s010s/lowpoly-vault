# Favosites material-only candidate

Baseline `17b421d6bdb2439ac110467205158cac883da4b5`; original GLB `59f7df72b3581e7100c22da1856ba9260b91e49e964771a414857fd09ae1731f`.

The existing artistic honeycomb-coral geometry is preserved. Only default metallicFactor 1 changes to 0, making shaded coral walls and transverse texture easier to read in the sampled views. Geometry, UV and embedded texture/BIN bytes are unchanged. This does not reconstruct colony biology or certify specimen accuracy/physical scale. Honeycomb openings are not blindly filled.

Candidate GLB `1b5311593b94f560d8bd1cde837f2c175a5f2a4e151bcf591bf755f8547ed9e0` is 2,509,576 bytes. A new editable Blend is imported from that exact candidate, textures packed, saved and reopened with equal recorded mesh/UV/image/material state. It is a new derivative, not recovered original authoring source. Original assets remain tracked and unchanged.

Four angles at desktop 1440 and simulated phone 390 compare default1 versus metal0 with explicit renderer.draw. Original double-view entry used 30 desktop and 4 mobile finite frames; the mobile sequence includes one timestamp reversal, so no continuous transition guarantee is claimed. Both actual GLB responses matched the original hash and recorded no HTTP/JS errors. Original 8/8 shared regression cases passed.

New paired wheel/detail images are captured from the actual candidate through the current production renderer. The temporary generation site intentionally had stale original poster bindings and is not accepted transition evidence. The first generation script waited for that obsolete binding and timed out; generation was corrected to wait for the actual renderer/model, not falsely approve the stale poster. The final candidate site uses the new exact-SHA bindings. The first build attempt lacked vite.config.js in the sparse checkout and failed before rendering; the tracked config was restored and the official build succeeded.

Candidate dual-end visual review, repeated-flow regression, independent review and unified-head CI remain pending. Not deployed.
