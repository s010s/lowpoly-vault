# Hand source and license

The bundled `v1-hand-18cm-relaxed.glb` is an adapted intermediate derived from Innerscene's Posable Anatomical Right Hand, itself based on MakeHuman core assets.

The original is a connected anatomical hand with 12,728 triangles and 16 skin joints. Its material is a plain color, with no third-party skin texture. The intermediate relaxed the pose, joined attribute-split vertices, and introduced an ArrivalOpen morph. The current revision further narrows the hand and index finger, defines the wrist, simplifies the faceted surface, and adds a matching triangular grid. These modifications are described and measured in the package README and validation files.

The final reference is calibrated to an illustrative 18 cm wrist-to-middle-fingertip distance. The 20 cm caption in the early visual concept is not the implementation standard. This is not an individual anthropometric measurement.
