## 生境和范围

Cobbania和Pluricarpellatia保持淡水湿地标签；前者是带基囊的杯状浮生叶，后者是水平根茎与盾形叶的有根浅水植物，不作为海草或海底植被。Sawdonia、Paratingia为陆地/岸边教学造型，不凭空推断耐盐/共生关系；Beelzebufo用友善静态蛙形，不强加毒性、捕食、跳跃机制或与这些植物同域共存叙事。珊瑚和两种海生小动物在海洋分区使用。整批不承诺同时代同地点生态复原。

Septarian是结核内部的矿物充填网络，Tafoni是圆风化穴与薄岩肋，Stromatolite是微生物丘的连续弧形叠层；后者在原inventory为traces/ecological-structure，不是珊瑚或植物。教学切面/露面只计同一ID的一种构图，不另计完整/破损/切片变体，且标为展示选择，不冒充实测标本或古地点原状。

所有名义尺寸都是美术起点，不是新量化石。窄干小树高0.9m、蛙体长0.22m、岩体/丘体尺度等见各项config；不能将每件统一缩为单位立方体，真实展示放大须另外标注。小个体需前景或明确展示尺度，不能承诺远处相机可辨。
