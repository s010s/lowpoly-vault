## 方法和结果

- **像素审查：** 逐项查看 `hero, reversehero, front, side, rear, top, clay, silhouette` 固定源视图，并检查候选清单中的 exact-GLB runtime 视图。实际 Chromium 重跑产出的四组 20 张图片与当前 manifest 逐张同 SHA；使用的是上述最终候选资产。runtime 为 Chromium + Three.js 0.180.0 / GLTFLoader + ANGLE SwiftShader software WebGL2，错误和失败请求均为空。六实例检查只证明本地功能渲染，不推断实体 GPU 性能。
- **源 / 导出：** 在隔离验证 worktree 用 Blender 4.3.2 只读重开四个精确 Blend；单位比例 1.0、identity 根变换、无 source camera/light。源审计 errors 为空，四件各自的导出网格均为 0 个非有限坐标、退化三角面、boundary edge 与 non-manifold edge。独立 source-export 检查三角面一致，轴变换后 bounds 最大误差：Echinochiton `4.1e-10 m`、Clypeina `0`、Tidal flat `6.1e-9 m`、Thalassinoides `0`。每份 Khronos glTF Validator 报告 0 errors、0 warnings。
- **新鲜重建：** 用 handoff 固定的 generator/config 在隔离目录对每项各重建两次；四组每次输出都与表中的目标 GLB 哈希和字节数一致。重建输出不覆盖候选 Blend、GLB 或报告。
- **round-trip 警告处置：** Blender 导入 GLB 后的检查为 `pass_with_warnings`、无错误。Echinochiton spine mesh 报 96 个导入边界计数；Thalassinoides 报 664 个，且它有意表现切开并通向剖切边的隧道腔。原始源部件审计边界/非流形边均为 0；逐视图检查没有发现意外破洞或悬浮管道。四项 `smooth faces require intentional-style review` 是平滑/混合着色提醒，并非导出失败。
