## 范围与独特结构

1项海生整体教学概念、2项壳/钙质管标本、2项植物器官、5项自然物和2项遗迹，共12。不是同物种冠密度、颜色、损坏、随机种子或尺寸变体。Pentremites长花瓣食沟芽体区别于旧螺旋沟杯；Diplomoceras长管发夹弯区别于直壳/盘卷带角壳，Clavagella是嵌小瓣的钙质瓶管，区别于钩曲双壳。

Schizoneura仅分节枝段浅浮雕，不臆造整株基部、根或活体丛；Nelumbo仅圆盾叶浅浮雕，有中央着生痕和放射区，不扩写莲花/莲蓬或现代种完整植株。两件壳标本不添加未知软组织或生活姿态。名义尺寸为美术起点，非化石测量；展示放大另标。

连岛沙洲必须连接大陆与岛体，不是旧沙嘴拉长；海成阶地体现高于当前岸线的旧台面与后方废弃海崖，不是现海面波切平台加厚。两件landscape保留原比例类别，18m/16m仅代表教学裁片，不是地貌全尺度测绘。水/灯光另作展示，不新增资产或承诺水体模拟。

角度不整合是真实截切的两组不同倾角层，区别于连续褶皱；渣状熔岩前缘有连续基体和不等大渣块覆盖关系，不能给绳状熔岩加噪声。自然铜枝晶在灰色仍有连续不等粗分叉和扁平端部，不用旧海绵/树枝换铜色。自然物不指定古地点、年龄、矿点、喷发事件或地层测量。
