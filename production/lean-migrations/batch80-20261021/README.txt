All original files are byte-identical at their original repository paths. The byte-identity map records source and QA commits and hashes. Original QA is retained unchanged, including nonaccepted candidates; it is not a new review. Final candidate files, original premodel freeze closure, actual source dependency closure and current proof are included. Old diagnostics, process-only logs/scripts, duplicate re-exports and consult-only source media are intentionally excluded. Historical absolute paths in original records are not rewritten.

This commit alone provides no website PASS, release approval, remote backup or deployment claim. Publication and exact remote readback are separate operations. No Blender was run for this migration.
