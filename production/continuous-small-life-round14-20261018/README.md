## 范围、场景和结构差异

3项海生整体教学概念、2项植物器官标本、5项自然物和2项遗迹，共12。Sidneyia是宽叠甲躯干—窄环腹—尾桨；Selkirkia是开放锥管、管中虫体和伸出吻；Conularia是四棱渐细体和折合口。不是旧动物改颜色/密度或同种年龄变体，软组织、微齿和未知细节经济简化，不承诺严格复原或动画。

Botrychium仅一件育性残片浅浮雕，成簇孢子囊连到枝轴，不能把未相连营养叶拼成整株。Dicroidium仅原Y叉叶器官，采用一种来源支持的羽片形，不混合分类群、不推断母株或额外繁殖器官。名义尺寸/弯曲/颜色属美术，非化石测量；陆地植物标本不当海底活体植被。

Barrier island为离岸长条沙岛分隔外海和潟湖，与连接陆岛的tombolo/伸入海中的sand-spit结构不同；waterfall plunge pool为掏蚀岩阶下的深潭，与独立河床壶穴/瀑布台不同。20m/8m为代表裁片，保留原landscape类别，不归一化小石或假称完整实地测绘；水/灯光另展示，不额外计资产或承诺流体。

洞穴boxwork是蚀退岩面上的相交残余薄矿物片墙，非垂挂帘、机械网格或三维玻璃泡沫换色。页岩碎坡体现可劈裂基岩下片状碎屑重力堆积，非火山渣块改色。布丁构造露头体现透镜体、颈缩和填入基质，非褶皱换波长或球体排队；灰色剖面仍有识别结构，不指定洞址、岩层年代或实际应变。

Diplocraterion保留sectional-structure，U管间连续spreite叠层片是新结构，非Arenicolites加表纹。Ophiomorpha亦保留结构剖面，平滑内腔/有颗粒外壁/连续壁厚是核心，非旧分支潜穴撒石。两者内部灰色剖面有信息，外底板轮廓不是识别gate；不指定制造者、行为事件或复制出土标本。

原worlds/packs/category/subcategory/taxon_group/eras/biomes/tags/representation/reconstruction_type在catalog_facets及完整inventory-record保留。研究专题包不等于发布包，海生动物、陆生植物器官、地貌/洞穴/遗迹是分区教学目录，不硬拼共存古生态；空时代/生境不自动普适。
