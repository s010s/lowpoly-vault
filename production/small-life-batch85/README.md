# Batch85 immutable local maker handoff

Four original concept-first low-poly candidates. Start with `maker-handoff.json` for exact revisions, artifact hashes, counts, bounds, source/rebuild provenance, stage states and limitations.

- Namacalathus r002: genus-level skeletal fossil-form, restored hidden stalk; no living soft tissues.
- Piedmont glacier r004: confined tongue joins broad spreading foreland lobe; rear interfaces repaired and original25-section sampling honored.
- Lava channel r002: inactive cooled sinuous open trough and unequal raised levees.
- Karst polje r002: broad flat sediment floor, uninterrupted irregular enclosing carbonate relief.

Original premodel briefs, source inventory, concept pixels/prompts/receipts and reference ledgers remain immutable under each r001 folder and `concepts/`. Delivery briefs add only postbuild artifact/dependency closure. All32selected final512px frames were rendered after exact GLB/brief/reference binding and personally inspected individually; lossless sheets retain full512px originals. The glacier's earlier full-view failure was retained and repaired in actual geometry, not hidden by a camera/material change.

Technical and Three.js parse stages passed. Fresh independent visual/factual/specification review, GPU and composed-scene stages remain unapproved or unrun. Nothing was uploaded or published by the maker.

Rebuild with Blender4.3.2: use `tools/generate.py` for the three r002 assets or `tools/generate-piedmont-r004.py` for piedmont r004, with `--config <asset/revision/config.json> --output <fresh directory>` after Blender's `--` separator. Acquire the shared production flock and run Blender with2threads. Repository `scripts/asset_common.py` and `scripts/qa_glb.py` are pinned dependencies. Do not install a second dependency tree. Generated asset sources are saved before proof-render scenes.

`qa/candidate-integrity.report.json` is a valid pending record, not acceptance. `qa/technical.report.json` binds compact official/project/source/two-rebuild raw reports. Process logs, duplicates and consult-only reference imagery remain in the local evidence archive pinned by the handoff; their paths are not public URLs.
