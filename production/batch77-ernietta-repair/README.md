## What changed

The original r004 failed independent static QA because its explicitly required basal zigzag suture could not be distinguished in any required512px view. This repair retains the original incomplete compressed, elliptical, open/truncated basal-sack fossil scope. It adds no trunk, fans, limbs, roots or feeding interpretation.

The real shared-vertex basal surface now has opposing lip fields joined through a recessed, long-axis zigzag groove. The basal juncture is slightly flexed forward, an illustrative preservation choice, not a claim to replicate a particular specimen. The original required front view visibly resolves the central join. Other angles can occlude it; no all-view visibility claim is made. The groove is not a painted line or circumferential decorative belt.

`repair-boundary-check.json` proves by read-only saved-source comparison that1,800 authored vertices covering the upper wall, rim and inner cavity, plus the cavity floor center, are exactly unchanged. Material definitions, object rotation and scale are identical. Only the lower four radial levels and new joining strip change. Grounding adjusts to the new actual minimum. The render script is a byte-identical copy of the original fixed-view renderer, with the same directions, resolution, settings and automatic bounding-sphere framing.
