# Remaining twenty: production-ready briefs

Only the remaining twenty subjects from the approved twenty-four are included. The first four pilot models are not remade here. All plans use the agreed stylized-inspired children’s-world tier: basic recognizable form, artistic color/texture/pose/proportions, six normal-scale views, zero production turntable frames, one consolidated independent review and at most one planned cosmetic repair. No individual user review is required.

Next batch A: Ichthyornis, Confuciusornis, Dapedium, Callichimaera.
Next batch B: Archaeopteryx, Longipteryx, Diplomystus, Burgessomedusa.

The other twelve are frozen in batches C–E. See batch-plan.json. Each subject has brief.json, build-config.json, references.json and freeze.json under its stable asset ID. Makers use GPT-6 Astra at xhigh in the authorized cloud, copy the frozen plan bytes into an isolated candidate bundle, and add the actual source/generator/config hashes in a versioned execution brief. Do not overwrite frozen candidate revisions. The config describes build intent; it is not a completed generator or evidence of a model.

References are consulted-only. Original geometry/maps must not copy source artwork, scans or meshes. Exact fossil uncertainty is advisory unless basic identity fails; choose the descriptive inspired-by fallback when necessary. Longipteryx is not commissioned as a fishing bird; the primary 2024 seed-ingesta result is noted. Callichimaera’s paddle legs are not repeated indiscriminately on every limb. Plant reproductive/vegetative forms stay one asset rather than duplicate variants.

Nominal scales are explicit design choices, not new fossil measurements. Very small subjects need close foreground placement or a clearly creative display-scale choice; their presence alone does not guarantee visibility from the distant island camera. All twenty are static, without a rig, flight/swim/wind cycle or animation-ready promise.

The four pilots’ independent basic-form and SwiftShader functional PASS was supplied by the parent task. This plan does not rerun or enlarge those verdicts into target-device performance. Functional software rendering and physical hardware benchmarking remain different claims. No site/museum files, main ref or existing release assets are changed.
