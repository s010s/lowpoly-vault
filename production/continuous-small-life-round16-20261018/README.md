## 独特结构、原范围与场景

2件海生整体教学概念、1件螺壳标本、2件植物器官、5件自然物及2件不同表现遗迹，共12。Eiffelia是圆形薄壁格囊和相扣星状格面，区别于纵翼锥杯/细管/分枝海绵，不是泡沫石换色；Facivermis前部五对带刺臂、长裸躯干与膨大后端，区别于全身均匀布足或管中虫。前臂/囊壁等主要形态应连续，微骨针/微刺经济简化。

Ecphora只原保存壳，沿原Miocene E. gardnerae gardnerae参考范围保留四道突出T形肋、圆壳圈/宽脐与水管沟，不是给普通螺壳粘等距薄盘，不加未知足/软体或以棕色当鉴定。Pseudofrenelopsis只渐细分节枝段、缩叶鞘缘与小叶尖，不假设整树冠；Pteleoidea只薄环翅果、中央隆起/顶缺口/细柄，母株及精确亲缘未知，不用旧漏斗萼果压扁凑新数。名义尺度/颜色是美术，展示放大另标。

Alluvial fan体现扇顶入流、坡脚扇面和浅分流，不是河海三角洲去水；karst spring mouth体现低洞口向短明渠的连续岩床，不是潮蚀洞缩小。18m/3m是名义教学裁片，保留原landscape类别，不声称全流域/完整扇测绘、泉流量、真实年代地点或模拟。水灯另展示，不计独立资产。

Cave pearl pool为浅矿物凹盆中的离散圆结核，非蛋窝改白或球阵；shatter cone rock为嵌套锥面断裂及方向一致放射纹，非贝壳断口加刻线。Lava tree mold crust为连续熔岩壳内深树干负形空腔/衬层/低树皮印，非外露熔岩柱、黑木头或独立空心柱。只计一件自然物，不再计树/木材，不从现代过程类比推断中生代实地。
